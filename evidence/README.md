# Verification artifacts

These files come from executed tests and real synthetic filesystem demonstrations. `demo/` contains screenshots, measured outcomes, manifests and unchanged-source checks. `test-results/` contains actual host/container test output. `reports/` contains sanitized derivatives of generated reports, clearly marked as redacted; original downloaded report hashes are retained in demo metadata.

Raw process listings, credentials, database files and runtime artifacts are excluded from the distributable archive. Sanitization changes report bytes, so sanitized hashes differ from original download hashes. Use the runtime report download for exact original bytes. No video recording is included.
